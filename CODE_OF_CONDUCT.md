# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We want participation in this project to be a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and constructive, also when you disagree.
- Focus on the problem, not the person.
- Accept feedback gracefully and give it kindly.

## Unacceptable behaviour

- Harassment, insults, trolling or personal attacks.
- Publishing other people's private information without permission.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Report unacceptable behaviour by using GitHub's **Report content** function or by opening a private
[security advisory](https://github.com/JH-Soft-Technology/acond-heatpump-ha/security/advisories/new) addressed to the maintainer.
The maintainer may remove comments, issues or contributions and temporarily or permanently block anyone who violates this code of conduct.
