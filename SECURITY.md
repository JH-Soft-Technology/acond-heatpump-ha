# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 2.x | ✅ |
| 1.x (YAML package) | ❌ |

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately via
[GitHub private vulnerability reporting](https://github.com/JH-Soft-Technology/acond-heatpump-ha/security/advisories/new).
You will get a response within 7 days.

Note: the heat pump's Modbus TCP interface has no authentication. Keep it on a trusted network and never expose port 502 to the internet.
